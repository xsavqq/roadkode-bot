# roadkode-bot

## Что нового в интерфейсе
- `/start`: баннер (`assets/banner.jpg`) + текст + inline-кнопки в две колонки.
  Если файла баннера нет, бот отправит просто текст.
- Калькулятор: цена в ¥ → вес → карточка «товар / комиссия / доставка / ИТОГО».
- FAQ: список вопросов, на каждый свой ответ (`handlers/menu.py`, список `FAQ`).
- Старые текстовые кнопки («🛒 Новый заказ» и др.) продолжают работать.

## Новые переменные окружения (необязательные)
- `REVIEWS_URL` — ссылка кнопки «Отзывы» (по умолчанию основной канал)
- `ASSORTMENT_URL` — ссылка кнопки «Смотреть в канале» под ответом «Ассортимент» (по умолчанию основной канал)
- `BANNER_PATH` — путь к баннеру (по умолчанию `assets/banner.jpg`)

## Оформление заказа (6 шагов)
1. Категория (баннер `assets/step_category.jpg`, кнопки из `ORDER_CATEGORIES` в `keyboards.py`)
2. Ссылка (`assets/step_link.jpg` — как скопировать ссылку в Poizon)
3. Размер (`assets/step_size.jpg` — где смотреть таблицу размеров)
4. Цена в ¥ (`assets/step_price.jpg` — сроки доставки)
5. Количество
6. Фото товара или `-` (если фото есть, AI оценивает примерный вес)

Категория уходит менеджеру вместе с размером, например «👟 Обувь / Кроссовки · 42».
Картинки шагов подключаются в `config.py` (`STEP_IMAGES`), баннер главного экрана — `assets/banner.jpg`.
