# roadkode-bot

## Что нового в интерфейсе
- `/start`: баннер (`assets/banner.jpg`) + текст + inline-кнопки в две колонки.
  Если файла баннера нет, бот отправит просто текст.
- Калькулятор: цена в ¥ → вес → карточка «товар / комиссия / доставка / ИТОГО».
- FAQ: список вопросов, на каждый свой ответ (`handlers/menu.py`, список `FAQ`).
- Старые текстовые кнопки («🛒 Новый заказ» и др.) продолжают работать.

## Новые переменные окружения (необязательные)
- `REVIEWS_URL` — ссылка кнопки «Отзывы» (по умолчанию основной канал)
- `ASSORTMENT_URL` — ссылка кнопки «Ассортимент» (по умолчанию основной канал)
- `BANNER_PATH` — путь к баннеру (по умолчанию `assets/banner.jpg`)
